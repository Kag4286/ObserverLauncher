● Built specifically for

  • Hosting dedicated Java or Rust servers on your Windows/Linux PC for friends without router setup.
  • Testing modpacks locally with 25/page Content pagination, conflict checks, and update rollback.
  • Inspecting offline playerdata/equipment and .mca worlds without adding heavy server plugins.
  • Java + Bedrock crossplay setups using Playit.gg, Pinggy UDP, and Geyser diagnostics.

● Honest limitations

  • Windows 10/11 (x64) and Linux (x86_64) only—no macOS build yet.
  • Built for personal PCs, not 24/7 multi-node VPS clusters (use Pterodactyl or Crafty for those).
  • Pumpkin and Horizon are upstream WIP Rust engines; Bukkit JVM plugins do not run identically on Rust.
  • Release installers are currently unsigned—Windows SmartScreen prompts once on first launch.

BEFORE YOU RUN

SmartScreen, Linux permissions & technical questions

Why does Windows SmartScreen warn when opening the .exe?
Open-source installers distributed without a paid EV code-signing certificate trigger Windows Defender SmartScreen until enough users run them. Click More info → Run anyway, or audit and launch straight from source via npm install && npm start.
How do I run the Linux .AppImage?
Download the latest .AppImage (or .deb), mark it executable with chmod +x ObserverLauncher-*.AppImage, and launch it normally. Tested on Ubuntu / Debian x86_64 (glibc 2.31+).
Does ObserverLauncher collect telemetry or require an account?
No. There is zero analytics or telemetry. Network calls happen strictly for server/mod/OpenJDK downloads, Mojang player skins, and tunnels or webhooks you explicitly turn on.
What tests back the v9.0.0 release?
Every build on main runs 185 Node unit/integration test files (NBT, world map chunks, path traversal guards, SSRF filters, design tokens, 7-locale i18n completeness) plus 17 Playwright Electron E2E tests on Windows and Linux.
