          05 / BEFORE YOU RUN
          
Windows SmartScreen & Linux setup

          

            

              Why does Windows SmartScreen warn when opening the .exe?
              

                Open-source installers without a paid EV code-signing certificate trigger Windows SmartScreen initially. Click More info, then Run anyway, or launch straight from source via npm install && npm start.
              

            

            

              How do I run the Linux .AppImage?
              

                Download the latest .AppImage (or .deb), run chmod +x ObserverLauncher-*.AppImage, and launch normally on Ubuntu or Debian x86_64 (glibc 2.31+).
              

            

            

              Does ObserverLauncher collect telemetry or require an account?
              

                No. Zero analytics or telemetry. Network requests run strictly for server/mod/OpenJDK downloads, Mojang skins, and tunnels or webhooks you turn on.
              

            

          

        


        

          06 / HONEST SCOPE
          
Where it fits, and where it does not

          

            

              
Built for

              
    
                
  • Hosting dedicated Java or Rust servers on your Windows/Linux PC for friends without router setup.
    • 
                
  • Testing modpacks locally with 25/page pagination, conflict checks, and update rollback.
    • 
                
  • Inspecting offline playerdata and .mca worlds without installing extra web map plugins.
    • 
              

            

            

              
Current limitations

              
    
                
  • Windows 10/11 (x64) and Linux (x86_64) only. No macOS build yet.
    • 
                
  • Designed for personal PCs, not 24/7 multi-node VPS clusters (use Pterodactyl or Crafty for those).
    • 
                
  • Pumpkin and Horizon are upstream WIP Rust engines; Bukkit JVM plugins do not run identically on Rust.
    •
