# ObserverLauncher 5.2.0

5.2.0 adds a **Beginner mode** — a simpler version of the app for first-time users, with every
advanced tool still one click away.

> This is the plain-English release note. Developers: see the full technical changelog in [CHANGELOG.md](https://github.com/Kag4286/ObserverLauncher/blob/main/CHANGELOG.md#520--2026-10-10).

---

## A simpler app for your first server

The app has a lot of power: ten server types, a marketplace, a world map, performance graphs, player
editing and more. That is great once you know your way around — but it is a lot to take in on day one.

**Beginner mode** fixes that. When it is on, the side menu shows only the four things you need to run
a server:

- **Overview** — start and stop your server
- **Console** — see what it is doing
- **Players** — who is on your server
- **Settings** — the basics

The rest (Performance, Marketplace, World Map, Server properties and more) is hidden, not gone. One
click on **"Show all tools"** at the bottom of the menu brings everything back.

## How you get it

You do not have to find it in a menu. When you first open the app, the welcome screen already asks
what kind of user you are:

- **"Create a new server"** (recommended for beginners) turns Beginner mode **on**.
- **"I already have a server"** (experienced) keeps the full app.

Either way, you can switch whenever you like in **Settings > Personal > Beginner mode**.

## A clear "your server is running" moment

When your server is running in Beginner mode, the Overview now shows a big card:

> **Your server is running!** Send this address to your friends so they can join.
>
> `192.168.1.42:25565`   [ Copy ]

That is the step most people get stuck on — sharing the address — so it is now front and centre, with
one button to copy it.

## Upgrading

Install 5.2.0 over your current version. No settings change, no migration. If you are an experienced
user, nothing changes unless you turn Beginner mode on yourself.
