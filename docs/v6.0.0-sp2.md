# SP2 Spike: Mojang Skin Fetch (PASSED)

## Goal
Verify we can resolve a username/UUID to a Mojang skin URL and download the PNG without external libraries.

## Result
**PASS**

## Implementation Details
- Username -> UUID: `https://api.mojang.com/users/profiles/minecraft/<name>`
- UUID -> Profile: `https://sessionserver.mojang.com/session/minecraft/profile/<uuid>`
- The `properties` array contains a `textures` entry with a Base64-encoded JSON payload.
- Base64 decode yields: `{ textures: { SKIN: { url: 'http://textures.minecraft.net/texture/...' } } }`
- Standard `fetch()` in Node/Electron downloads the PNG buffer.
- No rate limits hit during testing. The API is stable.

## Next Steps
- Store the fetched PNG in `userData/textures/skins/<uuid>.png` to avoid re-fetching.
- The renderer will need to render this image (either via `tex://` protocol or passing a `data:` URL / `file://` path).
