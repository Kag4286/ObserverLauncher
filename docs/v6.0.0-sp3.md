# SP3 Spike: Modded Icon Extraction (PASSED)

## Goal
Verify we can read a binary PNG file from inside a Minecraft mod `.jar` (which is a ZIP).

## Result
**PASS**

## Implementation Details
- `src/main/jar-read.js` already has a robust ZIP parser (`listEntries`, `readEntry`).
- It successfully found the PNG entry in a test ZIP and read the bytes.
- The current `readJarEntry` function calls `.toString('utf8')`, which corrupts binary files (e.g., 526 bytes becomes a 508-char string with replacement characters).
- To fix: Add a `readJarEntryBuffer(jarPath, entryName)` that returns the raw `Buffer` instead of calling `.toString('utf8')`.

## Next Steps
- Add `readJarEntryBuffer` to `jar-read.js`.
- In `textures.js` (or a new icon resolver), fallback to extracting the PNG from the mod jar if the PrismarineJS mirror fails.
