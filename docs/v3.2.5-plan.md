> (modpack CI/CD). No new features: harden CI, clean up debt, and fix the rough edges found after
> 3.2.0 shipped. The flake fix that was going to be a 3.2.0 re-tag is folded in here instead (a patch

> Tick an item only when it is written AND verified. Reference: `.agent/memory.md` (gotchas),
> `docs/v3.2.0-plan.md` (the feature it builds on).

## Why this version

- 3.2.0 shipped the modpack CI/CD pipeline. Running it on real tags exposed two operational bugs that
  a green `npm test` could not catch: a missing `npm ci` in the Docker job, and a third-party PaperMC
  outage failing the boot-smoke. Both are CI-hardening, not features.
- A patch release lets those fixes ship without pretending they are a new minor.
