    Advanced — port forwarding & firewall

    Friends on your WiFi can use the "Same WiFi" address as-is. For friends elsewhere, you can either forward this port on your router, or use the tunnel below. The button only opens Windows Firewall, it does not touch your router.

    Play over the internet — no port forwardingOFF▸

    Give your server a public address with Playit.gg — anyone with it can join.

    How?
    1. Click Set up Playit above — the app installs the agent and starts its background service.
    2. Open the Playit dashboard and sign in (free account).
    3. Create a Minecraft Java tunnel pointing at 127.0.0.1 on your server port (default 25565).
    4. Copy the public address it gives you and paste it below.

    Keep it on automaticallyStart the Playit service whenever the server runs, and stop it when the server stops.
    Bedrock crossplay (GeyserMC)OFF▸

    GeyserMC lets Bedrock players (phone, console) join your Java server. It needs a UDP tunnel in addition to the Java TCP one.

    Bedrock tunnel (Pinggy)OFF

    Pinggy opens a public UDP tunnel to Geyser so Bedrock players can join. The free tunnel lasts about 60 minutes and restarts automatically.

    Set up the Bedrock tunnel (technical)
    1. On the Playit dashboard, create a second tunnel: type Minecraft Bedrock, local port 19132, protocol UDP, and turn on Proxy Protocol v2.
    2. Set the bedrock port in Geyser's config.yml to 19132 (default). Floodgate handles Bedrock auth.
    3. Share the Bedrock address it gives you. Bedrock players add it under Servers.

    Playit's free plan cannot expose TCP and UDP at the same time, so the Java tunnel and this Bedrock tunnel are separate. A paid plan can combine them.

It scales dynamically with player count without pre-allocating gigabytes of RAM.
