OBS.03

IN PLAIN WORDS

What the launcher does not do.

A few things worth saying out loud so expectations match reality.

It runs on your machine

This is a desktop launcher, not a hosting service. When your PC sleeps, the server stops. You provide the hardware and the network.

Port forwarding is on you

The launcher opens the Windows Firewall for you, but your home router's port-forwarding rules are yours to set. The UI shows the exact address to share.

No cloud sync, no account

Your server files stay on your disk. There is no account, no telemetry and no sync between machines. That is by design.

Bedrock is out of scope

Only Java Edition servers are supported. Geyser/Floodgate work as regular plugins if you want Bedrock players to join.

OBS.05

THREE STEPS

From download to playable server.

A typical first run takes about three minutes on a decent connection.

Pick a folder

Where the server files will live. The launcher proposes a default folder but accepts any writable location.

Choose software & version

Vanilla, Paper, Purpur, Fabric… and a specific build. Downloaded from the official API with live progress.

Press Start & share

The launcher opens the firewall and shows the exact address your friends paste into their Minecraft multiplayer menu.

OBS.06

UNDER THE HOOD

No magic — just standard protocols.

Everything the launcher does is built on public, documented APIs.

Official sources only

Server jars and version lists come straight from Mojang, PaperMC, Fabric and Forge over HTTPS.

Standard RCON

Commands go through plain RCON with a locally generated password. Nothing proprietary.

Consistent backups

save-off → zip → save-on. Worlds are never archived mid-write.

Zero analytics. The full list of network endpoints is on the right.

OBS.10

QUESTIONS

Frequently asked.

Anything else — open an issue on GitHub.

Is ObserverLauncher free?

Yes — MIT licensed, forever. No ads, no accounts, no telemetry, no premium tiers.

Is it safe?

It's fully open source — every line is auditable. Servers are downloaded only from official APIs (Mojang, PaperMC, Fabric, Forge…) and the launcher never sends your data anywhere.

Which Java do I need?

Depends on your Minecraft version. The launcher checks this automatically and can install the right Java with one click, no admin rights required.

Which Minecraft versions are supported?

All of them that your chosen software supports — version lists are loaded live from official APIs, from 1.8 to the newest release.

Can my friends join from anywhere?

Friends on your WiFi connect directly. For friends elsewhere you'll need to forward a port on your router — the launcher shows the exact address and can open Windows Firewall for you.

Does it work with modpacks?

Yes — browse modpacks right in the marketplace and import a full pack in one click. The launcher downloads every mod and config file for you; no manual zipping, no missing dependencies.

How much RAM do I need?

The launcher itself idles around ~150 MB. The server is the hungry part: 2–4 GB is a sane start for a small Paper or Vanilla world; modpacks want more. You set the memory slider yourself.

Does it need internet all the time?

Only for downloads — server jar, Java, plugins. Once everything is local, a LAN world runs with the cable unplugged.

Can I run it on a VPS or headless?

It's a desktop app with a GUI. On a VPS you'd just run the jar directly; a CLI mode is on the roadmap.

ObserverLauncher is an unofficial tool, not affiliated with Mojang or Microsoft. Running a server requires accepting the Minecraft EULA.
